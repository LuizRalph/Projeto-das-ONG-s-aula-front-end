# 03 — Páginas públicas

Revisado em 26/10/2026.

O catálogo apresenta ONGs, projetos e oportunidades do banco, com filtros e descrição completa em modal. Resumos dos cartões não substituem o cadastro integral. O login oferece acesso ou criação de conta de voluntário. A transparência apresenta totais demonstrativos, sem publicar documentos privados ou controles administrativos. O site é multipágina; o frontend precisa da API PHP e não funciona integralmente pelo Live Server.

Referências: [README](../README.md), [modelo de dados](09-ESTRUTURA-DE-DADOS.md) e [relatório acadêmico](academico/RELATORIO-ACADEMICO.md).
