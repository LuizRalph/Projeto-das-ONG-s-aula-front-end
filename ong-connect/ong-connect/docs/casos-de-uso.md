# Casos de uso atuais

| Ator demonstrativo | Ações |
|---|---|
| Visitante | Consultar ONGs, projetos, transparência; solicitar cadastro |
| Solicitante de ONG | Enviar pedido; complementar após pré-aprovação no mesmo navegador |
| Voluntário | Consultar oportunidades; candidatar-se |
| Apoiador | Registrar contribuição simulada |
| Administrador demonstrativo | Analisar solicitações, salvar rascunhos, cadastrar/publicar ONGs, gerenciar projetos, candidaturas e doações, exportar relatórios |

**Não existe autorização real por ator**. Os papéis acima descrevem telas e fluxos, não permissões efetivas.
