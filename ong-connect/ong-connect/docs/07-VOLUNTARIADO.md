# 07 — Voluntariado

## Finalidade
Permitir que visitantes demonstrem interesse em oportunidades ligadas a projetos sociais e que o administrador simule a análise das candidaturas.

## Fluxo
1. Visitante localiza projeto/oportunidade e abre a inscrição.
2. Informa dados pessoais e informações sobre disponibilidade/interesse, conforme o formulário.
3. Envia a candidatura, que é registrada localmente.
4. O administrador abre **Voluntários**, consulta os dados e decide aprovar ou rejeitar.
5. A decisão fica registrada no histórico demonstrativo com responsável/justificativa.

## Regras
O código considera candidaturas aprovadas para calcular vagas disponíveis. A aplicação verifica duplicidade de candidatura conforme os campos e oportunidade. A rejeição é tratada como definitiva na interface atual. Não há mensagens externas nem contrato formal de voluntariado.

## Demonstração
Cadastrar uma candidatura fictícia, conferir no painel, aprovar e observar atualização da disponibilidade. Repetir com rejeição para mostrar as diferenças de estado.
