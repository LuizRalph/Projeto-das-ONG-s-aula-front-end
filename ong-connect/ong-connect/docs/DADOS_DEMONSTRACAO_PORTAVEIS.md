# Dados de demonstração e portabilidade

Revisado em 26/10/2026.

A instalação usa os JSON iniciais de ONGs/projetos/oportunidades. Isso não copia contas, candidaturas, doações, documentos ou todo o banco do servidor. Scripts antigos de demonstração local não são fonte de verdade da versão atual. Fixtures de integração só devem ser utilizadas em banco isolado. Para reproduzir a comparação acadêmica sem alterar dados permanentes, use [o experimento](academico/EXPERIMENTO.md).
